# AI Air Canvas

## About the Project

AI Air Canvas is a gesture-controlled virtual drawing application developed using Python, OpenCV, and MediaPipe. The application allows users to draw on a virtual canvas using hand gestures without touching the screen.

## Features

- Draw using hand gestures
- Select different drawing colors
- Eraser mode
- Clear the entire canvas
- Real-time hand tracking using a webcam

## Technologies Used

- Python
- OpenCV
- MediaPipe
- NumPy

## Installation

1. Clone the repository.

```
git clone https://github.com/YourUsername/AI-Air-Canvas.git
```

2. Install the required packages.

```
pip install -r requirements.txt
```

3. Run the application.

```
python hand_tracking.py
```
